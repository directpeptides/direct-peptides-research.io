# Direct Peptides Learning Center — GitHub Pages starter

## Publish
1. Create a new public GitHub repository (suggestion: `direct-peptides-learning`).
2. Upload all files in this folder to the repository root, including `assets/`.
3. Open Settings > Pages, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. Verify navigation, mobile layout, search filter and logo at the live GitHub Pages URL.
5. After the final URL is known, add canonical URLs and a sitemap.
6. Before approval and publication, review linked external categories, privacy draft and ownership/brand permissions.

No article drafts are included: the article campaign starts only after the two-site approval checkpoint.

The site is a planned educational resource; product details and scientific claims must be verified separately before adding them.
